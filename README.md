# Games API

This is my final project.

I made an API using Express.js and SQLite. The API stores games in a database and supports basic CRUD operations.

Features:

- Add a new game
- Get all games
- Get one game by ID
- Update a game
- Delete a game
- Filter games by genre using query parameters

The database is stored in a SQLite .db file, so the data stays saved even when the server is restarted.

I tested all routes using Postman.
